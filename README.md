# きづきカレンダー

1日3つの問いで、子どもとの日々に見えた出来事を端末へ残す React + Vite アプリです。

## できること

- 日替わりの3問と3択回答
- 断定・診断を避けた固定の振り返り文
- 任意のDify振り返り（回答とメモのみ送信）
- 過去月へ移動できるカレンダー
- 子育て相談で伝えたい要点と、月間記録から選んだ日をまとめた相談前整理シートを共有・印刷・PDF保存
- 端末内への写真保存、削除
- 写真を含む全記録の復元用JSONバックアップ
- OS標準共有（利用できない場合はクリップボードへコピー）
- キーボード操作、フォーカス制御、十分な文字コントラスト

## 安全性とプライバシー

このアプリは、発達・健康・親子関係を診断、評価、助言、保証しません。AI出力にも禁止表現のサーバー側チェックを行い、基準を満たさない場合は固定文へ戻します。

記録と写真はブラウザの `localStorage` に保存します。保存失敗時に古いデータを自動削除することはありません。写真は縦横最大900pxへ圧縮し、容量超過時は利用者へ知らせます。ただしアプリ独自の暗号化はないため、共用端末での利用や個人情報の保存は避けてください。ブラウザデータの消去や端末変更に備え、定期的なバックアップを推奨します。

Difyは利用者がチェックを入れた場合だけ呼び出します。送信対象は3つの質問・回答と任意メモで、写真は送信しません。

## ローカル実行

Node.js 24以降を使用します。

```bash
npm ci
npm run dev
```

検証コマンド：

```bash
npm run lint
npm test
npm run build
```

## Dify設定

APIキーをフロントエンドやGitHubへ保存しないでください。Vercelの Environment Variables に次を設定します。

| 変数 | 必須 | 内容 |
|---|---:|---|
| `DIFY_API_KEY` | はい | Dify Workflow APIキー |
| `DIFY_API_URL` | いいえ | 既定値は `https://api.dify.ai/v1/workflows/run` |

Dify Workflowの入力：

| 名前 | 型 | 内容 |
|---|---|---|
| `answers_json` | Text | 3件の質問と回答をJSON文字列で格納 |
| `note` | Text | 任意メモ（最大500文字） |

終了ノードの出力は `reflection`（推奨）または `text` にしてください。600文字以内の、観察事実を穏やかに整理する文章を返します。診断、発達評価、将来の保証、保護者への指示は含めません。

Dify未設定・通信失敗・安全基準違反の場合も、記録は固定の振り返り文で保存できます。

## 相談前整理シート

相談先へ伝える内容として、年齢月齢、主な相談、始まった時期、起きる場面と頻度、生活・発達の様子、得意なこと、役立った対応、相談歴、家庭の負担、希望する支援を任意で整理できます。日々の記録は初期状態で直近7件が選ばれ、必要な日を追加・解除できます。選んだ日の3問への回答だけが、付録として日付順に付きます。

この入力内容は画面を閉じると消え、端末への保存やDifyへの送信は行いません。シートは相談を円滑にするための保護者向け資料で、自治体や施設の正式な相談記録・診断書ではありません。

## デプロイ

Vercelでは `main` が本番へ自動デプロイされます。変更は作業ブランチでPull Requestを作り、Previewで動作を確認してから `main` へマージしてください。CIはLint、テスト、本番ビルドを実行します。

## 主な構成

- `src/App.jsx`: 画面と操作フロー
- `src/core.js`: 質問、固定文、日付ロジック
- `src/storage.js`: 端末保存、写真圧縮、バックアップ
- `src/reflection.js`: フロントエンドのAI呼び出し
- `api/reflection.js`: Difyへ接続するVercel Function
- `test/`: ロジック、保存失敗、AI安全チェックのテスト
