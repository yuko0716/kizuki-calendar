# きづきカレンダー

1日3つの問いで、子どもとの日々に見えた出来事を端末へ残す React + Vite アプリです。

## できること

- 30日 × 3領域 = 90問の観察のきっかけ
- 日替わりの3問と3択回答
- 任意メモ。スマートフォン標準の音声入力も利用可能
- 断定・診断を避けた固定の振り返り文
- メモのキーワードから、事前に確認・登録した公的な育児記事を最大3件表示
- 過去月へ移動できるカレンダー
- 子育て相談で伝えたい要点と、月間記録から選んだ日をまとめた相談メモを共有・印刷・PDF保存
- 端末内への写真保存、削除
- 写真を含む全記録の復元用JSONバックアップ
- OS標準共有（利用できない場合はクリップボードへコピー）
- キーボード操作、フォーカス制御、十分な文字コントラスト

## 日々の記録では生成AIを使わない

毎日の3問、メモ、保存、固定の振り返りは生成AIなしで動きます。音声入力はiPhoneやAndroidなどのキーボードが備える音声入力機能を使うため、生成AIは不要です。

関連する育児記事も、現在は生成AIでネット検索していません。`src/resources.js` に人が確認して登録した記事とキーワードを置き、メモの中に近い言葉があったときだけ表示します。該当する記事がない場合は、無理に推薦しません。

現在の初期リンク集は横浜市の公的な育児情報を利用しています。記事はアプリ内へ転載せず、元サイトを新しい画面で開きます。リンクを開くまで、利用者の記録本文をリンク先へ送ることはありません。

## 将来の生成AI利用

生成AIを使う場合も、役割を限定します。

1. キーワードそのものがなくても、記録の文脈から「ことば」「睡眠」「切り替え」など、あらかじめ決めたタグを選ぶ
2. 相談前に、利用者が選んだ複数日の記録から「よく見られた様子」「場面による違い」「前との変化」を事実だけで整理する

AIに育児記事を書かせたり、ネット上の記事を自由検索させたり、子どもの発達状態を判定させたりはしません。

## 安全性とプライバシー

このアプリは、発達・健康・親子関係を診断、評価、助言、保証しません。

記録と写真はブラウザの `localStorage` に保存します。保存失敗時に古いデータを自動削除することはありません。写真は縦横最大900pxへ圧縮し、容量超過時は利用者へ知らせます。ただしアプリ独自の暗号化はないため、共用端末での利用や個人情報の保存は避けてください。ブラウザデータの消去や端末変更に備え、定期的なバックアップを推奨します。

関連リンクの選択に写真は使いません。現在のキーワード照合は端末内で行い、記録本文を外部サイトへ送信しません。

## ローカル実行

Node.js 24以降を使用します。

```bash
npm ci
npm run dev
```

検証コマンド：

```bash
npm run lint
npm test
npm run build
```

## 相談に持っていくメモ

相談先へ伝える内容として、生年月日、主な相談、始まった時期、起きる場面、生活の様子、好きなこと、うまくいったこと、相談歴、家庭で困っていること、相談先で聞きたいことを任意で整理できます。日々の記録は初期状態で直近7件が選ばれ、必要な日を追加・解除できます。

この入力内容は画面を閉じると消え、端末には保存しません。相談を円滑にするための保護者向け資料で、自治体や施設の正式な相談記録・診断書ではありません。

## デプロイ

Vercelでは `main` が本番へ自動デプロイされます。変更は作業ブランチでPull Requestを作り、Previewで動作を確認してから `main` へマージしてください。CIはLint、テスト、本番ビルドを実行します。

## 主な構成

- `src/App.jsx`: 画面と操作フロー
- `src/core.js`: 質問、固定文、日付ロジック
- `src/resources.js`: 確認済み育児記事とキーワード照合
- `src/storage.js`: 端末保存、写真圧縮、バックアップ
- `test/`: ロジック、保存失敗、関連リンク選択のテスト
